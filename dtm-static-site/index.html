This data was collected using unmanned aerial systems (UAS)-mounted lidar sensors at Kinkaid Lake in the Shawnee National Forest, Illinois.

The objective of the project was to create detailed 3D models and digital terrain maps to track the impacts of erosion prevention projects in treed gullies.

Because these areas are challenging to access and survey using traditional methods, UAS-mounted lidar provides a practical solution for capturing high-resolution spatial data.

To learn more, visit the project blog post.
